This skill guides creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

## Design Thinking

Before coding, understand the context and commit to a clear aesthetic direction:

- Purpose: What problem does this interface solve? Who uses it?
- Tone: Choose a precise tone such as luxury/refined, editorial, art deco/geometric, organic/natural, industrial/utilitarian, or another distinctive direction.
- Constraints: Respect framework, performance, accessibility, existing functionality, and project rules.
- Differentiation: Decide what the user will remember visually and execute it consistently.

Choose a clear conceptual direction and execute it with precision. The key is intentionality, not intensity.

Implement working code that is:
- Production-grade and functional
- Visually striking and memorable
- Cohesive with a clear aesthetic point of view
- Carefully refined in spacing, layout, typography, images, and interaction details

## Frontend Aesthetics Guidelines

Focus on:
- Typography that fits the brand and improves readability.
- A cohesive palette with dominant colors and sharp accents.
- Lightweight motion and micro-interactions that improve the experience.
- Deliberate spacing, hierarchy, and layout rhythm.
- Backgrounds and visual details that add atmosphere without hurting usability.

Never use generic AI-generated aesthetics such as overused gradients, predictable SaaS layouts, stretched images, weak card systems, cookie-cutter spacing, or designs that lack context-specific character.

## Ecommerce UI Rules

For ecommerce or product websites:
- Hero sections must communicate product category and brand instantly.
- Product cards must have consistent image areas, clear names, size/category, price, and obvious CTAs.
- Product images must never stretch.
- Filters/search must be easy to scan and use.
- Cart drawers must feel like checkout, not debugging panels.
- CTAs should have clear hover, active, and focus states.
- Mobile layout must remain usable and polished.

## Final Check

Before finishing:
- Preserve existing required functionality.
- Run the project build command.
- Fix build errors.
- Summarize changed sections clearly.
